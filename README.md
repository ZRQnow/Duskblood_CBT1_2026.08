# Duskblood CBT1 行业研究库

本仓库用于整理 The Duskbloods CBT1 / Global Network Test 的测试资料，并在此基础上持续产出游戏行业分析。

这里不只是“存图片和视频”。理想状态下，任何一条研究结论都能一路追溯到：**它来自哪个来源、对应仓库里的哪个文件、文件里的哪一段画面或文字，以及我们从中确认了什么事实。**

## 这个仓库怎么用

可以把整个仓库理解成一条研究流水线：

```text
收集原始素材
↓
登记来源和文件
↓
从素材中提取可确认的事实
↓
按玩法、战斗、角色、社媒评价等主题做分析
↓
把分析整理成核心判断和报告
↓
检查证据与引用后形成最终版本
```

对应关系是：

`source_id → asset_id → evidence_id → claim_id`

- `source_id`：这条材料从哪里来，例如某个官方页面、某个测试玩家的视频、某条 Reddit 帖子。
- `asset_id`：这个来源在仓库里具体保存成了哪个图片、视频、网页快照或文本文件。
- `evidence_id`：从该文件中可以直接确认的一条具体事实，例如“视频 12:31 出现 3 名玩家共同攻击 Boss”。
- `claim_id`：由多条证据共同支持的研究判断，例如“游戏鼓励玩家在竞争关系中形成短期合作”。

## 基本原则

1. **原始素材尽量保持原样**：图片、视频、网页快照、访谈、社媒帖子等原件放在 `01_sources_raw/`。
2. **事实和分析分开写**：素材里直接看到或听到的内容放在 `02_evidence/`；对这些事实的解释和判断放在 `03_analysis/`。
3. **关键结论必须能找到原始出处**：分析引用 `evidence_id`，证据再对应具体素材、时间码、页面或截图位置。
4. **AI 优先读取整理后的索引和文本**：避免每次都重新扫描全部视频、图片和文件。
5. **CBT 结论只代表当前测试版本**：数值、平衡、玩法和玩家评价都可能在后续版本发生变化。
6. **不确定就明确标记**：不知道的内容写 `null` 或待核实，不用猜测值补齐。
7. **注意测试协议、版权和隐私**：不确定是否可以公开传播的材料先标记为 restricted/unknown。

## 最常用的入库流程

实际收集素材时，不需要每拿到一个文件就立刻完成所有步骤。建议按下面的顺序处理：

1. **先收素材**：新下载的图片、视频、网页、访谈等先放进 `01_sources_raw/_inbox/`。
2. **登记来源**：确认这份材料来自哪里，在 `source_register.jsonl` 分配 `source_id`。
3. **整理文件**：把素材移动到对应目录，并在 `asset_manifest.jsonl` 分配 `asset_id`。
4. **让素材变得方便 AI 阅读**：长视频做逐字稿和关键帧，图片做 OCR，网页保存可搜索正文。
5. **提取事实**：把真正值得分析的具体信息拆成一条条 `evidence_id` 写入 `observations.jsonl`。
6. **做主题分析**：例如集中分析战斗、角色、PvPvE、地图、社媒评价等，写入 `03_analysis/`。
7. **形成核心判断**：跨多个分析模块形成更高层结论，更新 `04_narrative/argument_map.json`。
8. **检查并输出**：完成 `06_qc/` 检查后，把正式成果放进 `07_final/`。

## ID 体系

- 来源：`SRC-类型-四位序号`，例如 `SRC-GMP-0001`
- 文件：`AST-六位序号`，例如 `AST-000001`
- 证据：`EVD-六位序号`，例如 `EVD-000001`
- 主张：`CLM-四位序号`，例如 `CLM-0001`

简单理解：

```text
一个 YouTube 实机视频
SRC-GMP-0001
↓
下载保存的视频文件
AST-000001
↓
视频 12:31 可以看到三名玩家一起攻击 Boss
EVD-000023
↓
结合其他录像，形成“竞争关系中存在临时合作空间”的研究判断
CLM-0004
```

同一个来源可以保存多个文件；同一个文件可以提取很多条证据；一条研究结论也可以由多条证据共同支持或反驳。

## 关于大文件和 AI 读取

图片、视频、音频等大文件继续通过 Git LFS 管理。

对于 AI 来说，几十分钟的原始视频通常不是最方便的第一读取对象。因此保留原视频的同时，尽量生成：

- 带时间码的逐字稿
- 关键帧
- 图片 OCR
- 网页正文文本
- `observations.jsonl` 中的结构化事实

AI 可以先通过这些内容找到需要的信息，只有需要核实细节时再回到原始图片或视频。
