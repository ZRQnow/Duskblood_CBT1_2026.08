# 01_sources_raw：原始素材存档

这里保存未经改写、裁剪、转码或标注的原始文件，以及能证明其出处的链接、页面快照和获取日期。

## 入库规则

1. 先在 `02_evidence/source_register.csv` 分配唯一 `source_id`。
2. 文件名使用 `YYYYMMDD_来源编号_主题_序号.ext`。
3. 同一来源的页面、媒体文件和伴随说明放在同一子目录或使用相同编号。
4. 不覆盖原件；来源发生更新时新建版本并记录 `supersedes_source_id`。
5. 发现隐私、NDA 或版权风险时，先停止提交，在台账中标为 `restricted`。

本目录下的材料只证明“来源中出现了什么”，不自动证明其陈述真实。分析和结论应写入后续目录。
