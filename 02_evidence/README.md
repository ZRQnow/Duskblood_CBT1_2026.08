# 02_evidence：证据与量化数据

这里保存从原始来源中提取、且可以回到具体文件、页面、时间码或截图复核的结构化事实。

- `source_register.csv`：所有来源的唯一台账，是跨目录关联的主索引。
- `frame_measurements.json`：动作、动画、延迟或持续时间的帧级测量。
- `ui_facts.json`：UI 中可直接读到的文本、数值、状态和位置。
- `rules_matrix.json`：玩法规则及其适用场景、例外和证据。
- `hiring_signals.json`：招聘材料释放的团队、技术和内容方向信号。

空数组表示“尚未采集”，`null` 表示“已知字段但当前未知”。不要用零、空字符串或猜测值代替未知。
