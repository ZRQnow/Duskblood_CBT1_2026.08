# 图片集合初步分析

## 研究问题

这批图片能够直接支持哪些关于《The Duskbloods》视觉呈现、比赛结构、空间设计和角色互动的初步判断？哪些内容仍不能仅凭图片确认？

## 当前判断

1. **哥特式城市与红月是当前样本最稳定的视觉母题。** 多张图片反复出现尖塔、教堂、钟楼、石拱门、屋顶与红色天体，说明这批素材集中呈现同一套哥特式城市语汇，而非多地图全貌（EVD-000001、EVD-000014、EVD-000025、EVD-000026、EVD-000028、EVD-000029）。
2. **场景强调明显的垂直层次。** 高处眺望、悬空结构、屋顶竞技场和飞艇等元素多次出现，至少从视觉设计上支持“高低差是空间识别的重要组成”这一判断（EVD-000001、EVD-000007、EVD-000010、EVD-000019、EVD-000025）。
3. **界面样本呈现阶段化多人比赛信号。** 角色选择界面列出六个 Bloodsworn；地图界面出现 I/II/III 阶段和 intermission；另有 PHASE END、淘汰文案及 GRAIL BATTLE 多人场景（EVD-000003、EVD-000013、EVD-000015、EVD-000019、EVD-000030）。这些图片能证明存在阶段、间歇、淘汰与多人终局等界面概念，但不能单独还原完整规则。
4. **战斗画面强调角色、敌人与环境事件的混合。** 样本同时包含大型敌人、多人同场、红色球体、Transmitter 事件卡与魔法符文等画面（EVD-000008、EVD-000011、EVD-000016、EVD-000017、EVD-000018、EVD-000021、EVD-000022）。这支持“画面信息不只来自直接 PvP”的初步观察，但仍不足以量化 PvP/PvE 比重。
5. **角色外形与装备差异明显，但技能定位不能由静帧直接确认。** 六角色选择画面、推进器样装置、圆环状武器和多种特效显示了视觉差异（EVD-000003、EVD-000006、EVD-000007、EVD-000009、EVD-000023）。文件名中的 allrounder、sniper、duo 等词未被当作证据。

## 证据与限制

- 39 张图片均已计算 SHA-256、尺寸和文件大小，登记为 AST-000001 至 AST-000029、AST-000034 至 AST-000043；AST-000030 至 AST-000033 为采访翻译稿。
- 11 个 WebP 为动画文件；本轮仅审阅其首个渲染帧，因此相关观察多为 `medium` 置信度，不能代表完整动作序列。
- `05_char_jan_melee.webp`、`06_char_tranglanh_vampiric.webp`、`18_phase_spawn.webp` 的扩展名为 `.webp`，但文件魔数为 JPEG。为保持原始材料不改写，本次保留原文件名并在素材标签和观察中说明。
- 图片组缺少可核验的逐文件上游 URL，当前编号为 01–37（缺 11）及 46–48；因此统一归档为待溯源的媒体图片集合，版权标记为 `unknown`，不把文件名中的媒体或角色词汇当成已确认事实。
- 宫崎英高肖像文件的身份与版权尚未通过可访问的原始页面复核，所以 EVD-000027 只描述可见人物外观，状态为 `needs_review`。

## 反证与冲突

- 样本高度集中于哥特城市、红月和战斗场景，可能是采集偏差，不能据此断言正式版所有地图或玩法均采用同一视觉风格。
- 单帧中的多人接近、跪地、伸手或近距离动作，不能区分合作、敌对、处决、剧情或系统交互（EVD-000020、EVD-000024、EVD-000029）。
- 动画文件名暗示的性能、闪避取消、双人模式、联盟等结论没有得到逐帧与时间码证据支持，因此未写入事实层。

## 行业比较

从界面语言看，阶段、间歇、淘汰和终局竞技场与多阶段竞技游戏常见的信息结构相近；但这只是视觉层比较，不能据此把产品归类为大逃杀、撤离玩法或传统竞技场。准确分类仍需结合规则文本、完整实机和访谈证据。
