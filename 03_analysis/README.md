# 03_analysis：主题分析

这一层回答“这些证据意味着什么”。分析允许比较、解释和推断，但所有关键事实必须回到 `EVD-*`。

## 当前一级主题

1. 核心循环与 PvPvE 结构
2. 战斗、移动、动作反馈
3. 局内目标、积分与 match flow
4. 角色、职责、build 与策略差异
5. PvE 敌人/Boss 与 PvP 的交织
6. 地图、关卡和动态事件
7. 局外成长、经济与 meta progression
8. 玩家临时联盟、背叛和社交行为
9. UI/UX、信息可读性和 onboarding
10. 网络、匹配、延迟、掉线与性能
11. 美术、音频、叙事与角色吸引力
12. 玩家/媒体评价及其分歧
13. 市场定位、竞品与受众
14. 留存、LiveOps 与商业化潜在线索
15. 项目、团队与制作信号

已有 `action_module.md`、`character_roster.md`、`economy_progression.md`、`project_signals.md`、`pvpve_loop.md` 继续使用。是否新增专题文件由 `analysis_index.json` 管理，不需要为每个主题提前制造空文档。

每份分析建议使用 `analysis_template.md` 的结构。不要只写“玩家普遍认为”；涉及社媒趋势时同时说明平台、样本数、时间窗口和采样方式。
